# Enviromental-Monitoring Group Project

Firmware for a prototype mesh sensor network using Raspberry Pi Zero and Particle Photon devices. Built for experimentation and demonstration of networking technologies including LoRa, S2C/serial inputs, packet transmission and reception, and microcontroller-based distributed systems.

# Achievements
•	Micro.P3.express project management
•	Successful LoRa transmission and reception
•	Readings including temperature and humidity
•	Device handshake for polling 

# Dependencies
Photon 2
•	Arduino_LoRa https://github.com/sandeepmistry/arduino-LoRa
•	SparkFun SHTC3 Arduino Library

Raspberry Pi
•	spidev
•	RPi.GPIO
